## Projekte

| Projekt | Kurz gesagt |
|:---|:---|
| **EnterpriseAI**<br><sub>im Ausbildungsbetrieb</sub> | KI-Assistenz im eigenen Netz: lokales Sprachmodell, Antworten mit Belegen, Anmeldung über Active Directory. |
| **OpenSignage**<br><sub>im Ausbildungsbetrieb</sub> | Digital Signage mit Live-Verbindung. Eine Änderung steht nach etwa einer Sekunde auf dem Bildschirm. |
| **Postfach-Vorsortierung**<br><sub>Vorführsystem</sub> | Die KI ordnet Mails ein und entwirft Antworten. Raus geht nur, was ein Mensch freigibt. |
| **Kundenportal**<br><sub>Net-Evolution</sub> | iOS-App für Freigaben, Belege und Meldungen. Betriebe streng getrennt, zweiter Faktor, Face ID. |
| **x-Height**<br><sub>InDesign</sub> | Setzt Schriftgrößen nach gemessener x-Höhe, für Pflichtangaben nach (EU) Nr. 1169/2011. |

<sub>Der Code ist nicht öffentlich. Postfach-Vorsortierung und Kundenportal zeige ich im Gespräch.</sub>
